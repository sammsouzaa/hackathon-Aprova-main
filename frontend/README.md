# frontend: Hub de contexto (React + Vite)

Tela de preparação da reunião: arquivos do cliente, contexto consolidado, checklist, regras e chat sobre o contexto.
Fala com a API em `../backend` (ver [`../backend/API.md`](../backend/API.md)).

```bash
npm install
npm run dev     # http://localhost:3000 (backend em :8000)
```

Normalmente suba tudo com `python rodar.py` na raiz. Variáveis: [`.env.example`](.env.example).
Referências de design: [`docs/`](docs/).
